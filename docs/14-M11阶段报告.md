# M11 阶段报告：一键安全释放 + 操作闭环

## 1．设计判断

前几轮功能提案被用户指出"伪需求"：分析层叠加（账单/体检/报告）只增加阅读成本，不降低决策成本。M11 转向**缩短从"看到"到"解决"的路径**，且要求与夜间海图视觉系统融合、逻辑与美观优先。

## 2．交付

- **一键安全释放**：只处理不需要人判断的两类——安全级缓存 → 回收站；重复文件组 → 自动硬链接合并（先合并后清缓存）。ReviewAdvised 项与大文件绝不动。确认弹窗列明两类数量与体积；执行后汇总报告并即时更新列表。
- **打捞方案行动区**：分析结果顶部 `action-panel`（海图缝线 + 磷光青数字），左侧可回收估算，右侧"一键安全释放"主按钮 + "在 3D 树中查看"入口，底部一行说明；手动勾选与"移入回收站"保留在下方 danger-zone，语义分层清楚（自动 = 安全，手动 = 判断）。
- **操作闭环**：缓存表与大文件表新增"操作"列——**定位**（`explorer /select` 选中文件，目录直接打开）与**复制路径**（绝对路径进剪贴板）。新增桌面命令 `reveal_in_explorer`。

## 3．验证

- 前端 tsc + vite 构建通过（修复 doQuickRelease 中误改 state 常量的 TS 错误，改为局部 next 累积）。
- impeccable 源码扫描无新发现；MSVC 桌面端重建启动。
- 建议用户路径：test-junk 分析 → 一键安全释放 → 观察重复组消失、缓存目录进回收站。
