# StorageScope Beta 测试指南

测试对象：`0.3.0-beta.2` pre-release。目标是发现真实环境中的启动、扫描、交互、升级和文件操作问题。

## 测试原则

1. 先创建合成目录，确认流程符合预期，再使用有独立备份的非关键数据。
2. 不要在唯一副本上执行首次清理或合并测试，不要为测试清空回收站。
3. 每项记录实际结果、版本、Windows 版本和复现步骤。未执行的项目保留“待测试”。
4. 诊断 JSON 分享前先打开检查；不需要提交个人文件内容。

## 合成样本建议

在专门目录中创建以下结构：

```text
beta-fixture/
  docs/
    keep.txt
    copy.txt
  cache/
    temporary.tmp
  large/
    sample.bin
  protected/
    important.txt
```

让 `keep.txt` 与 `copy.txt` 内容相同，并准备两个修改时间不同的文件用于快照差异。重复文件合并测试需要额外的独立备份。

## 故障反馈

在 GitHub Issues 选择 **Beta test report**，填写测试编号、实际结果和复现步骤。崩溃、数据不一致、保护边界失效或恢复失败请同时按 `SECURITY.md` 评估是否需要私密反馈。

## 当前外部依赖

代码签名证书、UAC 场景、其他 Windows 设备和版本、不同文件系统、第三方安全软件组合及真人测试尚未形成外部覆盖证据。这些项目需要在对应环境完成后单独更新结果表。
