# 故障排查

## 无法启动或窗口空白

- 确认系统为 Windows x64，并检查 Microsoft Edge WebView2 Runtime 是否可用。
- 重新下载对应 Release 资产，核对文件名、大小和 SHA-256。
- 关闭已有 StorageScope 进程后再启动或覆盖安装。
- 当前版本未签名，系统可能提示未知发布者。哈希不一致时停止安装。

## 扫描失败、结果不完整或文件数异常

- 检查目录是否存在、当前账户是否有读取权限，以及路径是否被其他软件移动或替换。
- 重解析点默认跳过并计入异常；这会影响完整性，但不会跟随链接进入其他目录。
- 取消后的结果只用于查看已收集的部分数据，不能保存为有效快照。
- 长路径和特殊文件可能返回具体错误。请保留错误文本，不要通过放宽路径或权限检查绕过。

## 清理目标被跳过

执行前复核发现目录清单、文件大小、修改时间、文件实体身份或重复锚点发生变化时，会跳过相关目标。重新扫描并生成新计划，不要直接把旧计划用于变化后的目录。

文件占用、权限不足、路径消失和回收站失败会按项目报告。部分成功不代表全部目标已处理。

## 空间没有立即增加

移入回收站的项目计入“待清空回收站大小”，卷可用空间需要结合回收站状态单独判断。重复文件仍有其他硬链接时，删除一个路径也可能没有分配空间释放。

## 合并中断

重新启动应用并扫描同一根目录。应用会核对备份和恢复记录，先恢复原路径，再允许新的合并。不要在恢复前手动移动或删除相关备份与记录。

## 更新检查失败

更新检查需要访问 GitHub API，并使用 Windows 系统根证书库验证 TLS。检查网络、代理、防火墙和系统时间。应用不会关闭证书验证，也不会自动下载或替换程序。

网络不可用不影响扫描、快照和本地清理功能。可以在网络恢复后重试，或手动打开项目 Release 页面。

## 安装、升级与卸载

- 覆盖安装前退出应用。
- 卸载会移除程序和快捷方式；本机验收中用户快照数据库得到保留。
- 免安装版移动目录不会自动迁移用户应用数据，继续使用同一 Windows 账户时可沿用原有数据。
- 当前没有完成需要 UAC 的提权安装场景验收。遇到权限提示时，记录实际提示与安装路径，不要以管理员身份进行清理测试。

## 导出诊断并反馈

进入“03 快照与趋势 → 导出诊断”，选择保存位置。JSON 包含版本、系统、架构和最近操作事件，路径使用 `$PATH_N` 占位。分享前仍需检查全文。

提交 Issue 时请附版本、Windows 版本、复现步骤、预期结果、实际结果和必要的诊断文件。不要在日志之外补充真实个人文件清单或敏感路径。
