# M8 阶段报告：趋势追踪（快照历史曲线 + 自动快照）

## 1．目标与结果

从"一次性清理"走向"长期监控"：快照区新增磁盘膨胀趋势图，并支持应用运行期间按间隔自动保存快照。

## 2．实现

- `ui/src/TrendChart.tsx`（纯 SVG，无依赖）：总量-时间折线 + 面积图；Y 轴体积刻度、X 轴时间刻度；**段间标注净增减**（增长橙色 / 缩减绿色）；数据点悬停显示快照号、时间、体积、文件数；顶部汇总区间净变化。仅统计状态为 complete 的快照。
- `App.tsx`：`SnapshotMeta` 补 `recorded_at`（核心库原有字段，直接透出）；快照卡片内嵌趋势图。
- 自动快照：间隔选择（关闭 / 15 分钟 / 每小时 / 每 6 小时），`setInterval` 触发既有 `save_snapshot` 命令；正在扫描时跳过本轮，防止并发写库。

## 3．验证

- 前端 tsc + vite 构建通过；MSVC 桌面端重建启动。
- 待用户验证：D:\mc 已有快照 #1 #2，趋势图应立即显示两点连线与净变化。

## 4．边界与后续

- 自动快照依赖应用保持运行；真正的后台无人值守需要 Windows 计划任务 / 服务，列入后续候选。
- 当前趋势为总量口径；后续可按顶级目录拆分多条曲线，定位"谁在膨胀"。
