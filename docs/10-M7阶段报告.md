# M7 阶段报告：视图联动（可清理项高亮）

## 1．目标与结果

打通"清理建议"与"可视化"：分析完成后，缓存命中目录与含重复文件的目录在 **3D 立体树 / 旭日图 / 冰柱图** 中统一高亮为橙色，并提供一键跳转入口。用户不再需要对照两张表手动找目录。

## 2．实现

- `App.tsx`：`cleanableDirs`（useMemo）= 缓存命中 `rel_path` 集合 ∪ 重复文件父目录集合；作为 `highlight` 属性传给 `Tree3DView` 与 `HierarchyViews`。
- `Tree3DView.tsx`：命中节点球覆盖为橙色（HSL 0.075/0.95/0.55），tooltip 追加"★ 含可清理项"；effect 依赖加入 `highlight`，分析完成即刷新场景。
- `HierarchyViews.tsx`：`nodeColor` 增加 highlight 参数，旭日图扇区与冰柱图格子命中即返回 `#ff9f43`。
- 清理建议操作行新增"在 3D 树中查看（橙色 = 可清理）"按钮：切换视图并平滑滚动回目录结构卡片。

## 3．验证

- 前端 tsc + vite 构建通过；MSVC 桌面端重建启动。
- 待用户在 D:\mc 实测：分析 → 跳转 → 橙色节点与清理建议表逐项对应。

## 4．边界

- 高亮精确到"目录"粒度：重复文件高亮其父目录，不代表整目录都可删，具体以清理建议表为准。
- 清理执行后分析结果会即时移除已删条目，高亮集合随之更新（cleanableDirs 依赖 analysis）。
