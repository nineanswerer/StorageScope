# 0.3.0-beta.2 本机验收记录

验收日期：2026-11-03。验收对象为当前发布目录中的最终 NSIS 与免安装 ZIP。所有窗口操作均在维护机上的隔离安装目录、隔离数据目录和合成样本中完成。

## 安装与升级

| 项目 | 实际结果 |
| --- | --- |
| 最终 NSIS 隔离安装 | 主程序安装成功，可进入真实桌面窗口 |
| 随附资源 | 第三方说明、使用指南、安全与恢复指南、故障排查文档均进入安装目录；NSIS 保留 `_up_/_up_/_up_/` 相对资源层级 |
| beta.1 → beta.2 覆盖升级 | Windows 文件版本由 `0.3.0-beta.1` 变为 `0.3.0-beta.2`，6 份快照保留，数据库 SHA-256 未变 |
| beta.2 卸载 | 安装目录、桌面快捷方式和开始菜单快捷方式移除，快照数据库保留 |
| beta.2 重装 | 重新显示已有的 6 份快照 |
| 免安装替换升级 | 在 beta.1 免安装目录副本中替换为 beta.2 文件，1 份快照保留，主程序哈希与 release 主程序一致 |
| 命令行窗口 | 安装版与免安装版验收均未发现附加 `cmd.exe`、PowerShell 或 `conhost.exe` 子进程 |

beta.1 阶段还实际通过了 v0.2.0 → beta.1 升级、免安装目录移动和对应生命周期验收。本轮没有重复执行这些已经通过的步骤。

beta.2 发布后，保留的 beta.1 免安装程序通过“检查更新”发现 `0.3.0-beta.2`，并通过“打开发布页”在 Microsoft Edge 打开对应 GitHub Release。

## 最终窗口复验

| 项目 | 样本与方法 | 结果 |
| --- | --- | --- |
| 取消扫描 | 1,000 个目录 × 1,000 个空文件；真实窗口点击取消 | 开始到取消约 2.90 ms，取消到可见不完整结果约 48.40 ms；取消后停留扫描页 |
| 3D 树 | 完整扫描 100,000 文件后，静止视图连续采集 120 帧 | 平均帧间隔 6.060 ms，约 165.02 FPS；p95 与最大帧间隔均为 6.20 ms；长任务 0，canvas 1 |
| 诊断导出 | 真实原生“另存为”对话框 | 导出 94 条事件，覆盖 5 类操作，包含取消阶段，受检路径均脱敏 |

这些数字是本机单次窗口验收结果。3D 采样期间没有旋转或缩放操作，不能据此推断其他 GPU、高负载交互或真实大型混合目录的表现。
